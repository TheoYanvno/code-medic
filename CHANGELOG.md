# Changelog

## 0.2.0

- Settings: turn Code Medic or single rules off, and change any rule's severity
- TypeScript rules: `no-explicit-any` and `non-null-assertion`
- "Fix all safe issues" command and a status bar issue count
- New rules: `parse-int-radix` and `bool-comparison`
- Inline `console.log` and `debugger` are removed without the rest of the line
- Template literals, block comments and Python docstrings that span lines are masked

## 0.1.0

- Diagnostics engine that masks strings and comments before rules run
- JavaScript, TypeScript and Python rules, each with a plain-English reason and two Quick Fixes
- Hover explanations
